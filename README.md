# Freelancr

An enterprise freelance marketplace connecting clients and freelancers with escrow-style payments, real-time messaging, contract lifecycle tracking, and administrative analytics.

For a full breakdown of the file structure, layered 3-tier architecture, database schema, Mermaid flowcharts, and feature/function dependency graphs, see:

## 🛠️ Tech Stack

- **Client**: React 19, TypeScript, Vite, Redux Toolkit, TanStack Query v5, Tailwind CSS v4, Socket.IO Client, Axios
- **Server**: Node.js, Express v5, TypeScript, MongoDB / Mongoose v9, Socket.IO v4, Razorpay, Cloudinary, Nodemailer

---

## 🚀 Quick Start

### 1. Server Setup
```bash
cd server
npm install
npm run dev
```

### 2. Client Setup
```bash
cd client
npm install
npm run dev
```
